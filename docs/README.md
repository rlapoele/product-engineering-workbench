# Documentation

This directory contains the long-term memory and working memory of the project.

The documentation is organized into four complementary areas:

- **knowledge/** — Stable knowledge describing the product.
- **planning/** — Living documents describing current intentions and priorities.
- **sessions/** — Summaries of discussions that may eventually crystallize into stable knowledge.
- **glossary/** — Canonical definitions of project terminology.

The repository follows a knowledge-first engineering approach.

Conversations are working memory.
Knowledge is long-term memory.
Planning describes the current execution strategy.

When in doubt, prefer updating an existing document rather than creating a new one.
