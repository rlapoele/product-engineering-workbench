# Workbench Visual References

These images are selected visual references for the Product Engineering
Workbench's own interface. They make the crystallized visual direction easier
to apply consistently in future UX exploration and prototypes; they are not
production UI specifications or implementation assets.

| Reference | Applies to | Notes |
| --- | --- | --- |
| [Public home, light](public-home-light.png) | Public home | Warm centered surface, editorial hierarchy, header controls and document-oriented preview. |
| [Authentication, light](authentication-two-column-light.png) | Sign-in and sign-up | Asymmetrical two-column entry screen; Google and GitHub are the only authentication paths. |
| [Project home, light](project-home-light.png) | Authenticated Project home | Project list is primary; Collaboration Requests appear only as project-linked attention summaries, not a global work queue. |
| [Project-start Context, light](project-start-context-light.png) | Project creation | The owner explicitly chooses Greenfield or Brownfield before Basics, Template, Preset and sections, and Create. |

Future screens should preserve the shared warm light-mode surface model,
restrained clay-orange accent, quiet global controls and document-first
hierarchy. They must still validate dark mode, interaction and accessibility
requirements independently.
