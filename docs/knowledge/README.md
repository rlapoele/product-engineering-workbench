# Knowledge

This directory contains the project's long-term memory.

Documents stored here describe stable or relatively stable knowledge about the product.

Typical contents include:

- Product vision
- Principles
- Product definition and product knowledge
- Architecture
- Data model
- UX
- AI orchestration
- Architecture Decision Records (ADRs)

Knowledge should evolve deliberately and only after ideas have matured through exploration and discussion.

When in doubt, prefer updating an existing document rather than creating a new one.
