# Architecture

This directory documents the overall architecture of the product.

Topics may include:

- System architecture
- Front-end architecture
- Back-end architecture
- AI orchestration
- Deployment architecture
- Executable slice specifications

Architecture documents describe how the product is designed, not how it is implemented line by line.

An Executable Specification may define the minimum source layout, public contracts and configuration boundaries required to implement an accepted slice. It remains a specification, not product code or a generic framework prescription.

When in doubt, prefer updating an existing document rather than creating a new one.
