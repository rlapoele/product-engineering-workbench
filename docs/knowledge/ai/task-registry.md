# Task Registry

**Status:** Not selected

The Workbench currently has no canonical `Task Registry` product concept.
AI participation is expressed through contributor capabilities, scoped
assistance requests, Observations and semantic Knowledge Engine operations.

This file is retained as an explicit boundary rather than an empty placeholder.
It must not be interpreted as authorization to introduce delivery tasks,
assignment, queues or agent work orchestration. If a future need requires a
registry of AI operations or capabilities, its purpose and terminology should
be decided before this document is expanded or renamed.
