# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs).

Each ADR documents:

- Context
- Decision
- Rationale
- Consequences
- Alternatives considered

ADRs capture the reasoning behind important technical and product decisions.

When in doubt, prefer updating an existing document rather than creating a new one.
