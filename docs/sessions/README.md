# Sessions

This directory contains summaries of product discussions.

Sessions represent the project's working memory.

A session typically contains:

- Context
- Key insights
- Decisions reached
- Open questions
- Suggested updates to project knowledge

Session summaries are intentionally concise.

They serve as the bridge between exploratory conversations and stable documentation.

Not every session results in changes to the project's knowledge.

When in doubt, prefer updating an existing document rather than creating a new one.
